# Circuit and e-design exports — 4.99.3

Circuit Compare offers a PDF comparison summary, a combined editable PDF, a self-contained HTML comparison and a CSV markup list. The editable PDF contains the original base pages followed by the developed pages, with the saved manual marks as native editable PDF annotations. Existing page annotations are retained. Editing a downloaded PDF does not automatically update the Circuit Compare session. The HTML contains drawing previews, markups, comments and the automatic change register; it has a 160 MB source-image limit and reports an error instead of truncating content.

e-design review also offers a self-contained HTML drawing review. Its existing editable review PDF and feedback import remain available, as well as the PDF report, CSV, Word and original PDF. HTML is a static snapshot. PDF annotations are editable only in PDF applications that support them.
