# Circuit Compare markup tools — 4.99.2

After comparing drawings, use the markup toolbar to choose a revision cloud, rectangle, arrow or comment area and a color. Drag on the base or developed drawing, enter a comment and save it. The visible callout and the markup comments list open the properties, where the comment, color and open/resolved status can be changed or the markup deleted. Markups are saved per comparison session and drawing side, independently of the automatically detected changes. Re-comparing creates a new session; earlier markups remain in the earlier session.

Share / export provides CSV and XML markup summaries and a PDF comparison summary with the marked page images and comments. The PDF is a static report; it is not an editable annotated source drawing. The original drawings and the existing change register are not modified. CSV values that could be interpreted as spreadsheet formulas are escaped. Markups use the comparison session's existing ownership checks.
