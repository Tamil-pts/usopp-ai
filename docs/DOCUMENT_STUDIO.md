# WorkHub Document Studio

Document Studio is the default editor for controlled engineering documents and MOM. Open Projects, select a project and its document, or open an independent record from Documents. Structured engineering tools remain available for execution results and specialized project tools.

Click text on a page to edit it. The Insert ribbon inserts content at the selection. Drag an Insert item onto a page or move an existing block using its handle. Select a block to resize it or edit its properties. Content stays connected to native project, requirement and test identities. Dynamic metadata uses project/document records; edit those records to change a project number, customer or approval status.

Page Design controls paper, orientation, columns, margins, typography, colors, watermarks and spacing. Header and Footer open visual designers with default, first-page and odd/even layouts. A section break has its own page and band settings. Tables support cell selection, merge/split, widths, colors and dynamic rows; checklists include Pass, Fail, Not Applicable and Remarks.

Smart Builder accepts guided answers, uploaded sources or original Tamil/English notes and reviewed meeting transcripts through Chopper. Chopper prepares a proposal. Review it alongside the retained source and explicitly apply it. It does not record test execution, sign documents or approve work. Translation quality depends on the configured local model and still requires human verification.

Review includes revision comparison, selected-text/cell comments, assigned corrections and clarifications, connected records and document quality checks. Related FRD/report records retain their native links; changed requirements expose records requiring review. Unresolved corrections and incomplete mandatory content block submission. Existing independent review, approval and release steps remain authoritative.

Layout templates preserve document content. The reusable content library accepts approved text, procedures and tables; signatures and recorded approvals cannot be copied as reusable approval. Protection controls in the properties panel lock content, geometry, headers/footers and templates. Only the lock owner or Admin may unlock an element. Approved revisions require a new revision before editing.

Controlled drafts save automatically. MOM uses Save draft and flushes edits before WorkHub navigation or workflow actions. PDF and DOCX export the selected saved revision. Approved Studio exports use frozen data and image snapshots. Legacy approved PDFs retain their original renderer and file. Word updates PAGE/NUMPAGES fields when opened or printed; pagination can differ with the fonts and Word version installed on the receiving computer.

Verification uses isolated databases and simulated records; no live PLC writes or synthetic employee competency scores are created.
